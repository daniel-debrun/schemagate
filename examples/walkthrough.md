# Walkthrough: three senders, one target table, one drifting export

Everything below is the unedited output of `examples/walkthrough.sh`, run from the repository root
on 2026-09-16 with the offline heuristic provider (no API keys). Timestamps and hashes differ per run.
To reproduce:

```bash
pip install -e '.[dev]'
bash examples/walkthrough.sh
```

The input files in `examples/data/` are synthetic and regenerated by `examples/data/make_examples.py`.

## 1. Set up a project

A project is a directory with `schemagate.yaml`, the registered target schemas, a SQLite governance store and a SQLite warehouse. The example target is `invoice_lines` (see `examples/schemas/supplier_invoice.yaml`). Three people take part: `dana` ingests and proposes, `omar` and `lee` review.

```text
$ SCHEMAGATE_ACTOR=dana schemagate init --schema examples/schemas/supplier_invoice.yaml
initialized schemagate project in walkthrough-run
[exit 0]
```

## 2. Ingest month 1 from three senders

Northwind sends a clean comma-separated CSV. BluePeak sends a workbook with a cover sheet and a line-item sheet whose header sits under three title rows. Cedar sends a semicolon-delimited cp1252 CSV with two preamble lines. Header rows (1-based in the output) and delimiters are detected; every value is stored as text with lineage columns in a raw staging table.
